# StartPos Finder

Quickly find practice and startpos copies directly from the `LevelInfoLayer`.

### Features
- **One-Click Search**: Adds a native button on any online level page to immediately find startpos levels.
- **Verified-First Sorting**: Authentic copies created directly from the original level (`m_originalLevel == targetLevelID`) are automatically sorted to the top.
- **Verified Badge**: Original copies get an aesthetic verified checkmark badge next to the level title, making it easy to identify genuine startpos levels and filter out nerfed fakes.
- **RobTop API Safe**: Automatically trims queries over 20 characters to prevent server `-1` errors.
