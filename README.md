# StartPos Finder

Geometry Dash mod for quickly finding startpos and copy levels directly from `LevelInfoLayer`.

## Features
- **One-Click Search**: Button on any online level page to immediately find startpos levels.
- **Verified-First Sorting**: Authentic copies created directly from the original level are automatically sorted to the top.
- **Verified Badge**: Original copies get an aesthetic blue checkmark badge next to the level title.
- **Query Normalization**: Strips repetitive copy suffixes and safely limits queries to prevent RobTop server `-1` errors.

## Compatibility
- **Geometry Dash:** v2.2081
- **Geode:** v5.11.2+
- **Platforms:** Windows, Android, macOS

## Installation
Download `scriptmanage.startpos_finder.geode` from [Releases](https://github.com/scriptmanage/StartPosFinder/releases/latest) and place it into your `geode/mods/` folder.
