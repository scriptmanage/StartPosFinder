# StartPos Finder

Geometry Dash mod for quickly finding startpos and copy levels directly from `LevelInfoLayer`.

## Compatibility
- **Geometry Dash:** v2.2081
- **Geode:** v5.11.2+
- **Platforms:**
  - Windows
  - Linux (Steam / Proton / Wine)
  - Android (32-bit & 64-bit)
  - macOS

## Installation
Download `startpos_finder.geode` from [Releases](https://github.com/scriptmanage/StartPosFinder/releases/latest) and place it into your `geode/mods/` folder.
